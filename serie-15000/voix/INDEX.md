# 🎙️ Index des voix

Format des fichiers : `NN_plan_PERSONNAGE.mp3`. Les fichiers `ouverture-A` et `ouverture-B` correspondent aux deux ouvertures possibles : n'utilise que celle qui a gagné le vote.

| Personnage | Voix | Réglage |
|---|---|---|
| Yanis | Rémy | un peu rapide |
| Vidal | Henri | lent et grave |
| Sofiane | Henri | rapide et aigu |
| Lina | Denise | vive |
| Nadia | Vivienne | douce |
| Gérard | Gérard (accent belge léger) | bourru |
| Bruno | Fabrice | très grave |
| Karim, Malik | Rémy | plus grave |
| Bernard | Gérard | très lent |
| Inès | Denise | rapide et aigu |

Version 2 : émotions par réplique (chuchoté, cri, larmes, téléphone…), phrases générées une par une avec de vraies pauses, traitement « micro » (compression, acoustique de pièce, léger bruit de fond). Pour un réalisme total, tu peux réenregistrer les répliques avec ta voix ou celle d'amis en suivant les mêmes textes.
